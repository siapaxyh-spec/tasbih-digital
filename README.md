# Tasbih Digital

Aplikasi tasbih berbasis web (HTML, CSS, JS murni, tanpa build). Bisa dipasang ke layar utama dan dipakai offline.

## Deploy lewat GitHub web dan Vercel
1. Di github.com buat repository baru (misal `tasbih-digital`).
2. Klik **Add file > Upload files**, unggah semua file proyek ini langsung di root repository (bukan di dalam folder), lalu **Commit changes**.
3. Di vercel.com pilih **Add New > Project**, impor repository tadi.
4. Framework Preset: **Other**. Kosongkan Build Command dan Output Directory, lalu **Deploy**.
5. Buka tautan hasilnya di HP, lalu pilih **Tambahkan ke layar utama**.
